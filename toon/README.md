# 手绘峡谷 · Toon Rift

卡通手绘风格的英雄联盟网页版。**没有任何外部模型、贴图或图片素材**，英雄、地图、树木、技能特效、图标和头像都由代码实时生成。

## 启动

在仓库根目录运行：

```powershell
python toon/serve.py
```

（`serve.py` 会禁止浏览器缓存，改完代码直接刷新即可；用 `python -m http.server 8196` 也能跑，但更新后需要 Ctrl+F5 强制刷新。）

然后打开 <http://127.0.0.1:8196/toon/>。只依赖仓库里已有的 `js/vendor/three.module.js`，无需联网。

## 内容

- **三十位英雄**：盖伦、德莱厄斯、艾希、凯特琳、阿狸、拉克丝、安妮、易、墨菲特、索拉卡，以及亚索、劫、金克丝、伊泽瑞尔、薇恩、提莫、锤石、布里茨、蕾欧娜、璐璐、莫甘娜、卡特琳娜、赵信、阿木木、布兰德、维迦、崔斯特、李青、蒙多、娜美。Q 版比例，用基础几何体拼装，带程序化动作（待机、跑步、攻击、施法、死亡），阿狸九尾、披风、马尾会随动作摆动。
- **120 个技能**：每个技能都有独立的特效与效果（伤害、护盾、减速、禁锢、魅惑、击飞、位移、钩子、风墙、影分身、牢笼、变形、传送、召唤提伯斯等）。对局从 30 人里随机抽出队友和对手组成 5V5。
- **选人展台**：点击技能或按 Q W E R 在训练假人身上预览；「全员合影」一次看全三十位英雄；左键拖动旋转视角。
- **法力与成长**：除盖伦（无消耗）外都有蓝条，技能消耗法力，随时间回蓝、泉水快速回满。英雄从 1 级开始，击杀或在附近阵亡的小兵、野怪、英雄、防御塔都给经验，最高 18 级，升级提升生命、攻击、法力。
- **技能加点**：每级 1 个技能点。Q/W/E 最高 5 级，且不能超过英雄等级的一半；R 最高 3 级，6 / 11 / 16 级解锁。技能等级越高伤害/治疗/护盾越强、冷却越短、耗蓝略增。电脑英雄会按各自的加点顺序自动加点。
- **金币与装备**：开局 500 金，补刀、击杀、助攻、野怪、推塔和时间都给金币。商店（P）有 29 件装备：小件、合成大件、鞋子和药水，已拥有的组件会自动抵扣合成价。单击查看，双击或右键购买；详情里画出合成路线树（已拥有的组件打勾）和「可合成为」；钱只够小件时，购买大件会先买得起的组件。📌 预定一件装备后，只要在泉水附近且金币足够就会自动购买（先买组件，凑齐后合成），HUD 背包下方显示预定进度；部分大件带独特被动（暴击、吸血、三相、飓风、冰杖减速、日炎灼烧、荆棘反伤等）。只能在泉水附近购买/出售，电脑英雄按各自出装路线回城购物。
- **商店老板**：双方泉水旁各有一位原创的富商大老板（油头、西装红领带、金表、拨金算盘），站在挂着「商店」招牌、堆满金币元宝的小摊后面。走近会招手说「欢迎光临」，右键点他打开商店（离得远会自动走过去）；商店里有老板头像和台词气泡，成交时场景里的老板会冒字撒金币。
- **回城**：4 秒读条，脚下展开手绘符文法阵、光柱逐渐升高、光点环绕上升；完成时原地和泉水各炸一道光柱，镜头自动切到泉水。
- **音效与音乐**：所有声音都用 Web Audio 实时合成（没有音频文件）：普攻、37 种技能/命中/爆炸/金币/升级/推塔等音效按距离衰减，外加程序生成的背景音乐。M 开关音效、N 开关音乐。
- **范围指示**：按住技能键显示射程圈和瞄准形状（直线、扇形、落点、目标高亮），不可施放时变红；鼠标停在技能图标上也会显示。指向敌人或按住 A 时显示攻击范围，左上角可设为常显。
- **目标面板**：攻击或指向敌人时，右上角显示目标的头像、等级、血量法力、属性、装备和战绩；小兵、防御塔、野怪显示精简信息。HUD 左侧是自己的属性栏，金币在头像下方。
- **手绘图标**：120 个技能、闪现/治疗和 29 件装备的图标都是 Canvas 画的小插画：水彩底、墨线描边、排线阴影。
- **手绘护手鼠标**：Canvas 画出的金色护手指针；悬停敌人变红、友军变绿，按下时握拳。
- **野区与野怪**：参照原版布局，每边 6 个营地——蓝 buff（蓝色哨兵）、魔沼蛙、三狼 / 红 buff（红色树精）、F4 锋喙鸟、石甲虫，河道里各有一只迅捷蟹；三狼、F4、石头人是一大带几小，打一只整营反击。击杀红蓝 buff 获得 90 秒增益（蓝：冷却缩减+回蓝；红：普攻灼烧减速+回血），击杀持有者可抢走。大龙坑、小龙坑凹在河道两侧的岩壁里。
- **战争迷雾**：只有友方英雄、小兵、防御塔和泉水周围有视野，其余地方变暗（小地图同步），视野外的敌人和野怪看不见也点不中。
- **召唤师技能**：闪现、治疗术、屏障、疾跑、引燃、虚弱、净化、传送、惩戒，在选人界面右下角二选二，冷却 60～240 秒；电脑打野带惩戒，其余随机，并会按场合使用。
- **阵亡提示**：倒下后画面褪成灰色，直到复活。
- **5V5 峡谷**：水彩手绘地面、流动的河流、分块实例化的森林、防御塔/水晶、兵线、野怪、小龙和男爵，电脑英雄会对线、打野、放技能和回家。

## 画风实现

| 效果 | 做法 |
|---|---|
| 赛璐璐明暗 | `MeshToonMaterial` + 三阶色阶贴图 |
| 墨线描边 | 背面外扩描边着色器（支持实例化），法线预先合并平滑，硬边也不断线 |
| 水彩地面 | 4096² Canvas 程序绘制：色块晕染、草叶笔触、土路碎石、河岸 |
| 纸张质感 | 屏幕上叠加程序生成的纸纹 + 暗角（multiply 混合） |
| 技能特效 | 手绘粒子图集（星星、云朵、爱心、火焰……）、地面符文圈、月牙刀光、光柱、漫画拟声字 |

## 操作

右键移动/攻击 · A 攻击鼠标附近的敌人（附近没有就攻击移动；前摇中右键可取消） · 按住 Q W E R 显示范围、松开施放（右键/Esc 取消）· Shift+Q/W/E/R 或点技能上方「+」加点 · D 闪现 · F 治疗 · P 商店 · 1-6 使用药水 · M/N 音效/音乐 · B 回城 · S 停止 · 空格镜头回中 · Y 锁定镜头 · Tab 战绩 · Esc 暂停 · 滚轮缩放 · 小地图左键看、右键走（右键时会在小地图上画出规划的路线）。
