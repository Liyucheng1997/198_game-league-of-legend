# 英雄联盟 · 网页复刻版

一个纯前端（HTML5 Canvas + 原生 JavaScript，零依赖）的英雄联盟致敬复刻，5V5 召唤师峡谷完整对局。

> 当前版本：**v1.1 · 岚铎：裂星壁垒**

## 怎么玩

任意静态方式打开即可：

- 直接双击 `index.html` 用浏览器打开；
- 或在本目录运行 `python -m http.server 8196` 后访问 <http://localhost:8196>。

## 已实现内容

- **英雄选择**：仿客户端深蓝金界面，含原创英雄“岚铎 · 裂星壁垒”和 5 名机制演示英雄，技能悬停预览
- **原创角色制作样例**：岚铎具备独立概念设定图、程序化分件模型、待机/奔跑/普攻/QWER 动作、铸火被动与专属技能特效
- **地图**：三路 + 河道 + 野区，外塔→内塔→高地塔→门牙塔（带前置塔保护机制）、三路水晶（可重生，摧毁后敌方出超级兵）、水晶枢纽、泉水回复
- **兵线**：每 30 秒一波（近战×3 + 法师×3，每 3 波一辆炮车），随时间成长
- **战斗**：普攻（近战/弹道远程）、暴击、吸血、护甲/魔抗减伤、护盾、控制（眩晕/禁锢/减速）、塔仇恨（打英雄会被塔集火且伤害递增）
- **成长**：经验共享升级（1~18 级）、技能加点（R 需 6/11/16 级）、补刀金币 + 被动收入、击杀/助攻赏金、连杀播报（一血/双杀/三杀…）
- **装备**：28 件经典装备（多兰系/无尽/帽子/三相/狂徒/鞋子…），泉水旁购买，右键出售
- **召唤师技能**：闪现（D）、治疗术（F）
- **中立资源**：小龙（永久团队 buff）、纳什男爵（强力团队 buff）
- **AI**：9 个电脑机器人分路对线，会补刀、放技能、越塔判断、残血回城、自动出装
- **其他**：战争迷雾（视野）、回城（B）、小地图（左键移视角/右键移动）、Tab 战绩板、击杀滚动播报、语音播报、合成音效、暂停/投降（Esc）、胜负结算

## 操作

| 按键 | 功能 |
|---|---|
| 右键 | 移动 / 攻击 |
| Q W E R | 技能（未学习时按键即加点，或点技能上方 +） |
| D / F | 闪现 / 治疗术 |
| B | 回城 |
| P | 商店 |
| Tab | 战绩面板（按住） |
| S | 停止 |
| 空格 | 镜头回到英雄 |
| Y | 锁定 / 解锁视角 |
| M | 声音开关 |
| Esc | 暂停 / 帮助 / 投降 |

## 文件结构

```
index.html        页面骨架（选人 / HUD / 商店 / 记分板 / 结算）
css/style.css     全部样式（LoL 风格深蓝金主题）
js/data.js        英雄 / 技能 / 装备 / 地图几何数据
js/engine.js      游戏引擎（单位 / 战斗 / 兵线 / 建筑 / AI）
js/render.js      Canvas 渲染（地形 / 单位 / 特效 / 小地图）
js/ui.js          HUD / 商店 / 播报 / 音效
js/main.js        选人流程 / 输入 / 相机 / 主循环
assets/heroes/    原创英雄概念设定与后续 DCC 源资产目录
```

原创角色“岚铎”的设计拆解、模型层级、动作表与技能验收标准见 [`docs/landuo-character.md`](docs/landuo-character.md)。
