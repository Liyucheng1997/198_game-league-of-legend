# v1.2 · 十英雄峡谷练习版

原来的地图和英雄演示已升级为使用真实地形、导航网格与经典英雄模型的本地模拟游戏，提供 5V5 人机和训练场。

[在线试玩](https://liyucheng1997.github.io/198_game-league-of-legend/)

- 首批十位英雄：盖伦、德莱厄斯、艾希、凯特琳、阿狸、拉克丝、安妮、易、墨菲特、索拉卡；40 个主动技能及主要被动。
- 2024 召唤师峡谷地形与原始网格，包含三路建筑、兵线、野区、草丛视野和寻路。
- 十个带骨骼和动画的经典 3D 模型；Data Dragon 14.24.1 的资料、图标和装备属性，运行素材均已本地化。
- 增加训练场、技能重施、控制与弹道碰撞、装备合成抵扣和鞋子升级；修复兵线卡墙、建筑保护与基地结算等问题。
- 调整选人和对局界面，适配窄窗口。

## 验证

23 项机制回归、旧版岚铎回归、113 份素材哈希及 10 个 GLB / 135 段动画检查通过。完整固定种子人机对局在游戏时间 67 分 41.5 秒触发蓝方胜利。浏览器验证了选人、模型加载、训练施法和装备合成。

## 当前还原范围

这是可玩的还原版本，尚未达到完整 1:1：经典英雄模型年代与数据补丁未统一，地图采用地形渲染图；建筑/野怪美术、完整技能数值、装备主动被动、符文、部分地图目标及多人网络规则仍待补齐。[素材来源与详细差异](https://github.com/Liyucheng1997/198_game-league-of-legend/blob/master/docs/restoration-status.md)。
