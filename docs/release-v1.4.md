# v1.4 · 手绘峡谷（2026-09-28）

这一版换了方向：从「还原原版素材」改为**卡通手绘风格**，所有英雄、地图、野怪、技能特效、图标、音效和音乐都由代码实时生成，不加载任何外部模型、贴图、图片或音频文件。

在线试玩：<https://liyucheng1997.github.io/198_game-league-of-legend/>（首页直接进入手绘版；旧版保留在 `classic.html`）。

## 画面

- 赛璐璐三阶明暗 + 背面外扩的墨线描边，屏幕叠加纸张纹理与暗角。
- 地面是 4096² 的程序化水彩画：草地笔触、土路碎石、流动的手绘河流。
- 野区参照原版布局：成块岩壁与通道、大龙坑和小龙坑凹在河岸岩壁里。
- 40 个技能、9 个召唤师技能、29 件装备的图标都是 Canvas 画的小插画；鼠标是手绘金色护手。

## 英雄与技能

- 十位 Q 版英雄：盖伦、德莱厄斯、艾希、凯特琳、阿狸、拉克丝、安妮、易、墨菲特、索拉卡，带程序化动作（剑圣普攻为左右交替横斩）。
- 40 个技能各有独立特效与效果；按住技能键显示射程和瞄准形状，松开施放。
- 法力、1～18 级成长、技能加点（大招 6/11/16 级解锁）。
- 召唤师技能二选二：闪现、治疗术、屏障、疾跑、引燃、虚弱、净化、传送、惩戒。

## 对局

- 5V5 人机：兵线、防御塔、水晶、泉水、回城（符文法阵特效，完成后镜头切回泉水）。
- 野怪：蓝 buff、红 buff、蛤蟆、三狼、F4、石头人、河蟹、小龙、大龙，红蓝 buff 可抢夺。
- 金币与装备：补刀/击杀/助攻/推塔收入，29 件装备、合成抵扣、独特被动；泉水旁的原创富商店主，左键打开商店、左键购买。
- 战争迷雾、右上角目标属性面板、左侧属性栏、小地图寻路路线、阵亡画面变灰。
- 程序合成的 37 种音效与背景音乐。

## 运行

```powershell
python toon/serve.py
```

打开 <http://127.0.0.1:8196/toon/>。页面会给脚本自动加版本号，更新后普通刷新即可。
