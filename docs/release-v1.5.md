# v1.5 · 聪明的电脑与三十五英雄（2026-10-15）

这一版的重点是**电脑英雄**：AI 从头重写，加入四档难度，困难以上会补刀换血、预判施法、躲技能、走 A、集火和运营。同时英雄扩充到三十五位，装备改版到 50 件。

在线试玩：<https://liyucheng1997.github.io/198_game-league-of-legend/>

## 电脑 AI

- **四档难度**：选人界面右下角选择简单 / 普通 / 困难 / 大师，记在本地。难度影响反应时间、躲技能概率、预判准度、补刀、激进程度和是否越塔；大师难度敌方金币与经验 +15%。队友最高按困难水平行动，没有资源加成。
- **分路**：按英雄定位分配上单、中单、下路、辅助和打野（下路双人），玩家占自己英雄最适合的位置；召唤师技能按分路选择。
- **对线**：预估友方小兵伤害来补刀，血量占优时换血，不进敌方塔的射程，有小兵抗塔时才推塔；辅助把兵让给射手。
- **施法**：沿目标的寻路路线预判落点，直线技能会避开挡路的小兵，范围大招瞄准敌人最密集处；控制和斩杀优先；不开战时只用远程技能消耗，位移技能留着开团。
- **躲避**：看到飞行道具后按难度决定是否侧身躲开，也会走出敌方短时的地面范围技能。
- **战斗决策**：按双方英雄、小兵和防御塔估算战力比，决定开战或撤退；自己血量越低越需要明显优势；能打出斩杀伤害时追击，追不上 2.5 秒就放弃；队友会集火同一个目标。
- **保命**：残血吃药、开中娅沙漏、用闪现/治疗/屏障/净化脱身，脱离战斗后回城；被防御塔锁定会先离开射程。
- **打野**：按距离清自家野区、抢河蟹，6 级后（困难以上）会反野；定时挑残血、压线过深或队友在旁边的敌人去抓。
- **团队**：中后期控小龙、大龙，人数和血量占优时抱团推敌方塔最少的一路，建筑被拆时回防，附近队友交战时赶去支援。

## 修复

- 战争迷雾是按玩家视野计算的，红方电脑因此打不了玩家看不见的野怪，打野严重掉级。现在迷雾只对玩家一方生效。

## 英雄与技能

- 新增五位英雄：**锐雯、卢锡安、内瑟斯、泽拉斯、蔚**，各有代码建模、被动、四个技能和手绘图标。加上上一批的亚索、劫、金克丝、伊泽瑞尔、薇恩、提莫、锤石、布里茨、蕾欧娜、璐璐、莫甘娜、卡特琳娜、赵信、阿木木、布兰德、维迦、崔斯特、李青、蒙多、娜美，共 35 位、140 个技能。
- 技能伤害除法术强度外，也随装备提供的额外攻击力提升，物理系英雄（劫、锐雯、李青、凯特琳 Q 等）出攻击装后技能同样变强。
- 全员合影改为四排，所有英雄都在画面里。

## 装备

- 新增中间件：灵巧披风、吸血鬼节杖、考尔菲德的战锤、暴风大剑、无用大棒、恶魔法典、巨人腰带、燃烧宝石、锁子甲、负极斗篷。合成路线不再有两千多金的断层。
