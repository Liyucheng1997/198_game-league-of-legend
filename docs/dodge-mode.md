# 走位挑战实现说明

## 模型
十英雄分别设定显示高度，待机姿态的双脚骨骼中点用于水平对齐。垂直方向按模型最低点落地，再使用相机投影计算 Canvas 的脚底锚点。武器、尾巴不参与水平居中。模型逻辑碰撞与美术外形分离。模型来自仓库已有经典档案，并非当前正式服模型。

| 英雄 | 技能 | 练习 |
|---|---|---|
| 拉克丝 | Q | 直线光球 |
| 阿狸 | E | 直线魅惑 |
| 艾希 | W | 九箭扇形 |

| 索拉卡 | Q | 延迟落点 |
| 墨菲特 | R | 冲向锁定落点，落点判定 |

| 易 | R | 追逐与保持距离，不伪造可躲 Q |

英雄机制参考 Riot 官方英雄说明：[拉克丝](https://www.leagueoflegends.com/en-gb/champions/lux/)、[易](https://www.leagueoflegends.com/en-sg/champions/masteryi/)。基础移速来自仓库已有 Data Dragon 14.24.1。弹道速度、范围、宽度和前摇均集中于 DODGE_KITS；此表是训练调参，不是完整补丁级认证值。近战追逐速度、额外前摇、闪现冷却专为单人练习设置；命中以次数表示，不附加原版硬控。所有人物统一 50 半径以保持练习一致性。

## 判定与计分
最多 1/120 秒子步；移动玩家和弹道使用相对位移线段检测，防止穿透。每个施法共享命中状态，散射多箭最多计一次。弹道飞完或区域结束才发放躲避分。10 次命中或 90 秒触发结算；暂停、失焦、切换页面均停止推进。最后 4 秒停止新增技能，留出结算时间。

## 验证
自动化覆盖十英雄轮换、全部形状结算、连续碰撞、不同帧率一致性、移动边界、闪现、暂停、命中计分和结束条件。模型与画面通过 models.html 和实际游戏浏览器检查。
