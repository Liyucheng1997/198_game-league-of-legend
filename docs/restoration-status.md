# 召唤师峡谷还原记录

版本：v1.2。更新：2026-09-10。当前是可运行的本地人机游戏，**尚未达到完整 1:1 复现**。下表区分原始素材、已实现机制与剩余差异。

## 素材和版本

| 内容 | 来源与固定版本 | 本地使用方式 |
|---|---|---|
| 十位英雄资料、原画、头像、50 个技能图标、装备、召唤师技能 | [Riot Data Dragon](https://developer.riotgames.com/docs/lol)，14.24.1 | 113 份本地素材，来源、字节数和 SHA-256 见 `assets/riot/manifest.json` |
| 十位英雄网格、纹理、骨骼和动画 | [tengge1/lol-model-viewer](https://github.com/tengge1/lol-model-viewer/tree/ef5635c5fbe0c315275c9bcccf83558cfe7ee436) | 自编转换器输出 GLB；原始 30fps 动画降采样至 15fps并保留时长；浏览器平滑插值 |
| 2024 召唤师峡谷地形 | [LoL-NGRID-converter](https://github.com/FrankTheBoxMonster/LoL-NGRID-converter/tree/92943ed2b2d5e82c86d680e69f53f247c89aefee/SR_2024) | 原图 8192×8192，转换为 WebP，运行时缓存为 4096×4096 Canvas |
| 墙体、草丛、建筑占地 | 同一 2024 档案的 VisionPathing / LSGNGRID | 295×296 原始网格，区分实体墙、透明墙、草丛和基地门；200×200 A* 导航 |
| 三维运行库 | Three.js 0.160.1 官方 npm 分发 | 已本地化；保留 MIT 许可证 |

经典模型的年代早于 14.24.1，包含视觉更新前的造型；不能把这些模型称为当前客户端模型。Data Dragon 原画 URL 不隔离补丁，已保存下载时的校验值。地图使用原始地形的二维渲染图，英雄使用三维骨骼模型合成到画面，建筑、野怪、小兵、召唤物和多数特效仍由本项目绘制。地图图像与逻辑网格采用归一化坐标和基地锚点近似对齐。

素材中的英雄和游戏美术归 Riot Games。档案仓库代码许可证不等于 Riot 游戏素材授权。各来源记录和许可证随文件保存；本项目为个人学习用途，与 Riot Games 无关联。

## 对局系统

- 双方各五人，选人预览和实际阵容一致；可选上路、打野、中路、下路和辅助。
- 三条兵线、22 座防御塔、6 座可重生水晶、基地保护链、超级兵和基地胜负判定。
- 草丛隐蔽、墙体视线、插眼、战争迷雾；迷雾画面使用低分辨率遮罩，视觉边界未精确复现墙后阴影。
- 十二个野区营地、两只河蟹、巨龙和男爵；营地离开范围后回巢回血，提供击杀奖励、增益和刷新计时。
- 右键移动攻击、攻击移动、闪现越墙落点、治疗术、打野惩戒、回城、泉水恢复、技能加点、击杀助攻及战绩。
- 28 件装备读取官方属性和价格；已支持可购买组件抵扣、鞋子升级、六格装备栏、官方卖价、技能急速、法穿和韧性。
- 训练模式：满级、15000 金币、友方和敌方训练目标、重置状态、无限冷却、全图视野和生成兵线；训练中可随处购物。

## 验证与重建

```powershell
python tests/assets.test.py
node tests/landuo.test.js
node tests/rift.test.js
node tests/match.test.js
python scripts/fetch-riot-assets.py
python scripts/build-champion-models.py
python scripts/import-rift-map.py
```

`rift.test.js` 覆盖十位英雄的四十个主动技能、关键重施/控制交互、真实网格与营地可达性、建筑保护、装备合成及十分钟模拟。`match.test.js` 使用固定随机种子验证完整人机对局能到达基地结算。素材转换脚本需要 Python、Pillow 和 NumPy；运行游戏不需要安装这些库。

### 本轮验证记录

- 官方素材 113 份 SHA-256 与来源记录一致；10 份 GLB 结构、骨骼属性和共 135 段动画检查通过。
- 23 项机制回归通过，包括全部 40 个主动技能、近端弹道阻挡、凯特琳大招拦截/打断、德莱厄斯斩杀重施、小兵避让墙体和装备合成。
- 原有岚铎回归通过；JavaScript 语法与 Git 差异空白检查通过。
- 浏览器在 1440×900 和窄窗口验证选人、真实地形、模型、训练、技能与商店。加载状态显示 10/10 模型，未记录脚本错误。
- 浏览器实际购买暴风之剑再合成无尽，金币从 15000 → 13700 → 11400，组件被替换；凯特琳 R/Q 触发击杀，W 充能由 3 变为 2。
- 人机对局耗时随装备、碰撞修正变化，验证允许最多 90 分钟模拟时间；这不是强制结束比赛的规则。
- 2026-09-10 最终完整人机回归通过：固定种子 241，模拟时间 67 分 41.5 秒，蓝方摧毁红方基地并进入胜利结算。
