# 岚铎 · 裂星壁垒

这是项目中第一个从视觉设定、战斗机制到游戏内模型完整落地的原创英雄样例。概念图位于 `assets/heroes/landuo/concept-sheet.png`，专用头像位于 `assets/heroes/landuo/portrait.png`，游戏内可运行模型采用 Canvas 2D 分件骨架绘制，不依赖外部运行库。

## 角色定位

- 定位：上路 / 重装战士 / 开团副坦
- 核心体验：靠近敌人、累积铸火、选择合适的强化技能，再用大招重置战斗循环
- 视觉关键词：深青重甲、陨铁巨刃、熔金裂纹、不对称堡垒肩甲
- 轮廓原则：左肩高、右肩低；武器宽而单刃；无传统骑士披风与蓝金纹章，确保与现有英雄区分

## 技能组

| 按键 | 技能 | 实际效果 | 满铸火强化 |
|---|---|---|---|
| 被动 | 熔芯 | 基础技能积累铸火，模型头顶三枚铆钉显示层数 | 满 3 层后强化下一基础技能 |
| Q | 断岳横斩 | 前方扇形物理伤害与减速 | 更大范围、130% 伤害、0.8 秒击晕 |
| W | 铸垒回响 | 护盾、减伤，2.5 秒后范围震裂 | 150% 护盾，震裂附带 40% 减速 |
| E | 熔痕突进 | 向目标方向突进并伤害路径敌人 | 留下持续伤害和减速区域 |
| R | 天坠·裂星 | 跃击目标区域，造成混合伤害，中心击晕 | 落地后直接获得 3 层铸火 |

## 程序化模型层级

```text
LanduoRoot（朝向与跳跃位移）
├─ SelectionRing / ForgePips
├─ Cape
├─ Legs
│  ├─ LeftLeg + Boot
│  └─ RightLeg + Boot
├─ Torso
│  ├─ ChestPlate + ForgeCrack
│  ├─ BastionShoulder.L
│  └─ Shoulder.R
├─ Arms
├─ Helmet + EmissiveVisor
└─ Greatblade
   ├─ Grip / Guard
   ├─ MeteorIronBlade
   └─ EmissiveCrack
```

这套层级直接映射到 `js/render.js` 中的绘制函数。每个部件都有独立局部坐标和旋转，因此不是一张随着角色平移的贴图。

## 动作表

| 动作 | 驱动方式 | 主要可读性 |
|---|---|---|
| Idle | 呼吸正弦循环 | 胸甲轻微起伏，武器保持警戒 |
| Run | 11Hz 交替步态 | 双腿反相、双臂轻摆、身体前倾 |
| Attack | 0.34 秒非线性挥砍 | 巨刃从右后方快速扫到左前方 |
| Q | 0.48 秒大幅横扫 | 武器弧度更大，并配套橙金刀光 |
| W | 0.62 秒防御姿态 | 双肩外扩、正面生成六边形能量壁 |
| E | 0.38 秒拖刀冲锋 | 身体前倾、刀刃贴地、路径留下熔痕 |
| R | 0.82 秒跃击 | 起跳抬升、抛物线轨迹、星形裂地冲击 |

## 若升级为真正的 3D 资产

1. 按概念图在 Blender/Maya 中制作 12k–18k 三角面的游戏模型，武器单独建模。
2. 使用 2 套 2048×2048 PBR 贴图：Body 与 Weapon；通道为 BaseColor、Normal、ORM、Emissive。
3. 建立约 55 根骨骼的人形骨架，肩甲与武器各用独立辅助骨；根骨承担位移。
4. 按上方动作表制作循环与一次性动作，导出 glTF/GLB；动作事件标记命中帧、起跳帧和落地帧。
5. 浏览器版可引入 Three.js 加载 GLB，但战斗判定仍由当前 `engine.js` 负责，动画事件只负责表现，避免帧率影响数值结算。

## 验收标准

- 选人界面能显示概念图头像与全部技能说明。
- 进入游戏后，岚铎有区别于圆形占位符的完整分件轮廓。
- 移动、普攻、Q/W/E/R 均出现不同模型姿态和特效。
- 每个基础技能会正确积累或消耗铸火；R 落地充满铸火。
- 仍保持标准 5v5 队伍规模，新增英雄不会产生第六名机器人。
